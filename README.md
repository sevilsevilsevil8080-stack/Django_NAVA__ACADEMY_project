# 🎓 NOVA ACADEMY

A full-stack educational platform built with Django.

NOVA ACADEMY is an online learning platform where students can create an account, explore courses, enroll in courses, manage their learning progress, and handle course payments.

---

## ✨ Features

- 🔐 User registration and login
- 👤 Personalized student dashboard
- 📚 Course listing and course details
- 🎓 Course enrollment system
- 💳 Course payment system
- 🌐 Persian / English language support
- 🌙 Light / Dark mode
- 📱 Responsive design
- 🛠️ Django Admin panel
- 👨‍🎓 Student profile management

---

## 🛠️ Technologies

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite
- Django Internationalization (i18n)
